# PRL 计算内核审查：中文说明

最新状态：MIT 开源 SOAT 已编译并验证，在 220W 稳态测试中比原始内核提高约 9.7%，也已通过自己的管理入口的矿池、启停和让路验收。见[当前后端选择与实测证据](COMPUTE-BACKEND-COMPARISON.md)。下文保留初始调查背景，不代表当前运行状态。

2026-10-28；本机 RTX 3090 24GB。当前完成的是源码审查，还没有测出新内核的性能提升，也没有切换正在挖矿的任务。

## 先分清四层

- **PRL / Pearl**：挖的币和网络。
- **Kryptex**：现在使用的矿池，派任务、记账和结算。
- **KRig**：真正调用 3090 计算的矿工程序。
- **RainbowMiner**：启动、监控和选择矿工的管理软件。

通用的 Stratum 协议用于矿工与矿池通信；RainbowMiner 的适配器用于启动具体矿工并读取其统计。补适配器不需要换矿池，也不意味着修改了 GPU 内核。相同 KRig 和参数下，换管理软件本身不会提高算力。

## 能不能掌握计算核心

可以研究公开的 CUDA 实现，但要同时看源码、许可、显卡架构和矿池协议：

| 项目 | 能研究什么 | 当前限制 |
| --- | --- | --- |
| Open-Pearl-Miner 当前版 | Ampere Tensor Core 内核 | 自定义许可，发布衍生版须保留原 2% 开发者费；目前接 LuckyPool |
| 同一作者早期 MIT 提交 | 可追溯的完整 Pascal/DP4A 源码 | 不是新版 Tensor Core 性能；后续新增代码需分别核对许可 |
| Nacre Miner | 标注 MIT，包含 SM86 源码 | 代码来源与署名还需核对；目前接 LuckyPool |
| CanaryMiner | MIT 源码，已有 Kryptex 协议 | 当前只支持 RTX 50 系列，3090 需要移植并验证 |
| KRig | 可控制启动参数，读取统计 | 公开仓库未提供可编译的 CUDA 内核源码 |

详细的固定版本、许可证、源码位置和证据见 [英文评审](KERNEL-REVIEW.md)。不能根据“仓库放在 GitHub 上”就认定计算内核也公开了。

## 性能实验怎么判断有用

先验证计算和证明正确，再在相同功率、热稳定后比较。除了显示的 TH/s，还看无效/过期份额、难度加权的有效工作量和费用。现在 220W 的 KRig 是基线；只有真实实验才能说明新方案是否更快、更省电。

当前源码发现的研究方向包括：3090 专用的分块和流水线参数、复用任务初始化缓冲、减少命中份额时的数据回传停顿。它们都还只是待测假设。原项目已经做过的 Tensor Core、内核融合、批量检查、后台提交证明，不算我们的新成果。

同矿池、同地址、同结算方式下切换矿工，池内余额会继续按该地址记账。切换前仍须验证矿池协议和真实接受份额；不会仅凭界面数字就宣布成功。

另有官方 PIP-3 浮点协议提案，当前是 Draft、部署待定，所列硬件是 Hopper/Blackwell。它不是“3090 已经不能挖”的公告，但值得在投入大量 Ampere 优化前留意。
