## 后续最有价值的性能工作（尚未实施）

1. **给 KRig 增加原生适配器。** 这个基线没有 KRig；OneZeroMiner 的 PearlHash 配置列出 NVIDIA 1% 开发者费，BzMiner 列出 2%。本机已验证的 KRig 在当前 Kryptex 池为 0% 开发者费。相同有效算力下有减少这层费用的机会，最终必须实测净收益，不能只比显示的算力。
2. **限制首次基准测试范围。** 只选 NVIDIA、PearlHash、Kryptex 和一个矿工，避免全算法、全矿工轮流跑基准。这能缩短准备时间，不代表计算内核更快。
3. **相同功耗比较频率搭配和矿工。** 延续当前 GPU 功耗、核心/热点/显存温度、矿池接受的加权工作量和整机墙上电量记录。冷热起点、热稳定、难度变化与费用都应保持可比较。当前这一轮体验没有追加此类测试。
4. **单独审查 Web/API 与下载链路。** 默认页面应只在本机/受控网络使用。上游还依赖远端矿池元数据、价格和程序下载。只移除捐赠地址远程覆盖，不等于整个应用已经离线，也不等于下载的每个矿工都开源。

## 验证方法与限制

`Tests/Test-Fork.ps1` 使用纯 PowerShell，无额外 Pester 依赖。它校验 PRL 主网 Bech32m 校验和、模块相对配置路径、真实 Core 的 TLS-only 过滤表达式、费率预算、关闭行为、错误策略、池不可用，以及执行真实 Core 捐赠状态切换片段，检查普通钱包对象不变、轮次结束/配置错误后恢复原对象。网络、时间记录和日志接口用本地 stand-in；不启动矿工或调用矿池。

另验证启动默认值、未保留自动杀毒排除调用、ZIP 更新器在副作用之前退出，以及修改文件的 PowerShell 语法。PowerShell 7 和 Windows PowerShell 5.1 的实际结果保存于本机测试产物目录；同一脚本可接入 CI；当前未配置云端 CI。

尚未验收 GUI 的实际点击、软件下载、矿工启动、真实捐赠份额、收益提升和所有跨平台启动方式。当前 KRig 一次体验任务保持独立，到 1 PRL 后收尾，不被本仓库测试替换。
